
# CUB3D

A brief description of what this project does and who it's for


## Tech Stack

C, Raycasting, DDA


## Run Locally

Clone the project

```bash
  git clone https://link-to-project
```

Go to the project directory

```bash
  cd CUB3D
```

Compile

```bash
  make
```

Run

```bash
  ./cub3d ./test_maps/valild/...
```
